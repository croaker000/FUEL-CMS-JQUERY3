# FUEL CMS
FUEL CMS is a [CodeIgniter](https://codeigniter.com) based content management system. To learn more about its features visit: http://www.getfuelcms.com

# THIS FORK
Fuel CMS has been sunsetted. It's still a great customisable CMS, it's just that the tech is too old and it looks like the Daylight Studios people have moved on. So, this fork has taken v1.5.2, swapped in jQuery 3.7.1 and fixed all the resulting problems with the built-in javascript libraries. We've taken the opportunity to swap in the latest (last) free version of CKEditor (v4.22.1). We also added all the appropriate outstanding pull requests from the original repo and added some of our own. We now (nominally) have a PHP 8.5 compatible CMS. This includes moving from the vanilla CodeIgniter 3 to the [pocketarc fork](https://github.com/pocketarc/codeigniter) that's concentrating on the latest PHP support.

### Installation
To install FUEL CMS, copy the contents of this folder to a web accessible folder and browse to the index.php file. Next, follow the directions on the screen. 

### Upgrading
Get yourself to the vanilla 1.5.2 version from the Fuel CMS site. If you have an old installation. follow their instructions for getting from 1.4* to 1.5.2. After that, just upload this lot over the top.

### Documentation
To access the documentation, you can visit it [here](http://docs.getfuelcms.com).
